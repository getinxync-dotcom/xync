# Changelog

All notable changes to the Xync website will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-04

### Added
- Initial release of Xync website
- Home page with hero section and value proposition
- About page with company story and team information
- Services page with three service tiers
- Ops Clarity Index: interactive 12-question assessment tool
- Contact page with Typeform integration and booking calendar
- Responsive navigation with mobile hamburger menu
- Single-page application (SPA) routing without page refreshes
- Scoring engine for operational maturity assessment
- Three-stage classification system (Overwhelmed Operator, Structured Grower, Systems-Led Business)
- Intent scoring for lead qualification
- Google Sheets integration for assessment data collection
- Clean, professional design with custom color scheme
- Mobile-first responsive design
- Zero external JavaScript dependencies
- Comprehensive documentation (README, DEPLOYMENT, CONTRIBUTING)
- MIT License

### Technical Details
- Pure HTML, CSS, and vanilla JavaScript
- CSS Grid and Flexbox layouts
- CSS custom properties for theming
- Google Fonts (Syne, DM Sans)
- Single HTML file for easy deployment
- ~100KB total file size
- Optimized for fast loading

### Browser Support
- Chrome/Edge (latest 2 versions)
- Firefox (latest 2 versions)
- Safari (latest 2 versions)
- Mobile browsers (iOS Safari, Chrome Mobile)
